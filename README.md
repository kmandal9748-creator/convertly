# Convertly

Free, private PDF toolbox. Everything runs in the browser (no server, no uploads).

## Deploy on GitHub Pages
1. Create a repo named `convertly` and upload `index.html`, `style.css`, `app.js`.
2. Repo **Settings → Pages → Build from branch → `main` / root → Save**.
3. Your site goes live at `https://<your-username>.github.io/convertly/`.

## Notes
- Word/Excel/PowerPoint export extracts text or page images; complex layouts are simplified.
- Compress, Unlock, Protect and PDF/A re-render pages as images (text becomes non-selectable).
- PDF/A output targets PDF/A-1b but is not certified; validate with veraPDF if compliance matters.
